# website-scripts

Front-end JavaScript loaded on every page of branchpattern.com (animations, smooth scrolling, the project map, the team grid and navigation effects).

`scripts.js` was originally written by Antenna for the BranchPattern website and copied here unchanged from their repository (commit 4080ceb) so the site no longer depends on an outside account.

The site loads it through jsDelivr, pinned to a specific commit. To change it, edit `scripts.js` here, commit, and update the commit in the Webflow Footer code.
